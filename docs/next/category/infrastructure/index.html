Infrastructure

📄️ Infrastructure Overview

UnifiedBeez runs on AWS in the eu-west-1 (Ireland) region. Infrastructure is defined as code using AWS CDK (TypeScript) and organised into 10 independent stacks that are deployed in dependency order.

📄️ Environments

UnifiedBeez runs across two named environments. A staging environment is planned but not yet provisioned.

📄️ Deployment

UnifiedBeez is deployed to AWS using CDK. Both the infrastructure stacks and the application containers are deployed separately.

📄️ Secrets Management

All credentials are stored in AWS Secrets Manager. No secrets live in environment variables, .env files, or source code in production.

📄️ DR & Backups

Disaster recovery and backup configuration for UnifiedBeez production infrastructure.
